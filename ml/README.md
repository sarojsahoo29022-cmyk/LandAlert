# GeoShield — Landslide ML Service (FastAPI)

Trains a binary landslide classifier on the Nepal historical dataset and serves
live predictions over HTTP. The Next.js dashboard calls this service.

## Files
- `train.py` — trains the model, saves `model.joblib` + `predictions_snapshot.json`
- `api.py` — FastAPI service with `/predict`, `/health`, `/snapshot`, `/districts`
- `model.joblib` — trained pipeline (generated by train.py)
- `predictions_snapshot.json` — per-district risk snapshot (generated by train.py)
- `requirements.txt` — Python deps

## Setup (already done once)
```
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Train the model
```
.venv\Scripts\python.exe train.py
```
Metrics from last run (test set):
- ROC-AUC: 0.986
- Accuracy: 0.961
- Recall: 0.920  (catches 92% of landslides)
- Precision: 0.747
- F1: 0.825

## Run the API
```
.venv\Scripts\python.exe -m uvicorn api:app --host 127.0.0.1 --port 8000
```
Interactive docs: http://127.0.0.1:8000/docs

## Endpoints
- `GET  /health`     — model status + metrics
- `POST /predict`    — body:
  ```json
  {"T2M":15.0,"precipitation":120.0,"rainfall_3day_sum":250.0,
   "rainfall_7day_sum":400.0,"rainfall_30day_sum":800.0,
   "temp_7day_avg":14.0,"district":"Kaski"}
  ```
  returns `{ "district", "landslide_probability", "risk_level", "prediction" }`
- `GET  /snapshot`   — all 78 districts with risk + level (for map/alerts)
- `GET  /districts`  — list of district names

## Integrate with the Next.js dashboard
From the frontend, fetch from `http://127.0.0.1:8000` (run the API alongside `npm run dev`).
Example:
```ts
const res = await fetch("http://127.0.0.1:8000/predict", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify(features),
});
const data = await res.json(); // { landslide_probability, risk_level, ... }
```
For district map/alerts, load `/snapshot` once and render risk levels.

## Notes / caveats
- The model uses `district` (one-hot) + rainfall/temp features. District encoding
  can dominate, so some districts show high baseline risk even at zero rainfall.
  This is acceptable for a demo; retrain with richer live features for production.
- Data is historical Nepal (1982–2019); UI context is North-East India — fine for
  a prototype, swap the dataset to local data when available.
- `datasets/_extra/` holds redundant files (not used by the model).
